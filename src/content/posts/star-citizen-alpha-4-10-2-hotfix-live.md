Star Citizen's live Persistent Universe remains on **Alpha 4.10.2 "RSI Discovery"**, which went live on **October 9, 2026**, bringing new RSI Discovery event missions, physics netcode updates and the new RSI Constellation Mk V.

## The hotfix is now fully deployed

According to community trackers ([Cavalera](https://cavalera.news/editions/2026-10-14); [SC Advisory](https://www.sc-advisory.space/)), hotfix **12913470** is now live on both the server and client side. The server-side fix addressed a critical "hybrid" crash; the client-side fix targets a high-impact HDR crash. With both promoted to Live, the HOTFIX test channel was closed.

## Another server fix in canary

Overnight (Oct 14–15), a further server-side build (**DGS 12939222**) began canary testing on several shards. It reportedly includes multiple server crash fixes and a repair for the RSI Discovery Month event total score, which wasn't adding up correctly.

> **Unconfirmed:** a CIG developer on the Evocati test thread reportedly said internal testing would pause for a day or two, with hopes of resuming on a new "Genesis" build by Friday. We have relayed this from a community digest and have not seen it in an official Comm-Link.

## Our take

Hotfixes landing quickly after a patch is a good sign. If you're hunting Discovery Month event points, keep an eye on whether the score fix makes it to all shards.
