**NieR: Automata on Steam just asked some players for a third of a terabyte.** After the latest Steam update added Simplified Chinese, Traditional Chinese and Korean language support, the install dialog started showing a storage requirement around **366.56GB** — far above the roughly 50GB footprint players were used to. That is not the game ballooning into a modern AAA download. It is a bug, and Square Enix's NieR side has already said so.

## What the official account confirmed

The [official NieR PR account (@NieR_JPN)](https://x.com/NieR_JPN/status/2118520550851281206) posted that after the latest Steam update, the install process was showing a higher-than-expected storage requirement. The team said it is investigating the cause and working on a fix, and apologized for the inconvenience. That acknowledgment is the official line — short, clear, and aimed at Steam players hitting the bad number.

[AUTOMATON West](https://automaton-media.com/en/news/nier-automata-developers-working-on-fix-after-update-accidentally-raises-steam-versions-file-size-from-50gb-to-366gb/) and [Dexerto](https://www.dexerto.com/gaming/square-enix-responds-after-nier-automata-update-triggers-massive-366gb-storage-requirement-3425350/) both report the same update as the trigger: new language packs for Simplified Chinese, Traditional Chinese and Korean. AUTOMATON notes this is the first Steam update for *NieR: Automata* in about five years, with the previous one landing on July 15, 2021.

## Why Steam shows ~366GB

Outlets tracing the Steam properties say each of the game's **eight DLC** entries is incorrectly listing a full-game-sized download. Stack those bad numbers with the base game and you get a install requirement north of 360GB — AUTOMATON cites about **366.56GB**. Once the game is actually installed, reporting still puts the real footprint around **40–50GB**. [VGC](https://www.videogameschronicle.com/news/nier-automatas-latest-update-increases-game-size-from-50gb-to-366gb/) earlier noted that RPG Site had tested the inflated requirement, and that the Steam store page still advertised **50GB** while the bad ask showed up at install time.

## Workaround while a fix cooks

The [@NieR_JPN](https://x.com/NieR_JPN/status/2118520550851281206) post itself is about the storage display and the investigation — it does not spell out a workaround. Separately, AUTOMATON and Dexerto report a temporary path attributed to Square Enix guidance: open the game's Steam **Properties → DLC**, uncheck the listed DLC, install the base game, then re-enable the DLC afterward. That sequence is meant to dodge the stacked fake size check so you can get back into YoRHa without clearing half a drive first.

**PPR take:** This is the kind of Steam bug that looks catastrophic in a screenshot and mostly annoying once you know what it is. A language update for Chinese and Korean should have been quiet good news for a nine-year-old classic, not a viral "366GB" freak-out. Credit where it is due: @NieR_JPN owned the bad storage number quickly instead of leaving players to argue in the reviews. The DLC-size stacking explanation also tracks — Steam was apparently counting the whole game over and over rather than shipping a sudden 300GB of new assets. If you were about to reinstall for another Automata run, hold the panic and use the reported DLC-uncheck path, or wait for the fix the PR account already said is in progress. Either way, the real game is still a ~50GB install, not a hard-drive hostage situation. Square Enix and Platinum should squash this fast so the language pack lands the way it was supposed to: as support for more players, not as a meme about storage.
